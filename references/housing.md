# 租房、申请与 Lease 审核

## 最少输入

- 学校/公司或大致区域、入住日期、lease 长度
- 月 all-in 上限、可接受的一次性费用、通勤上限与出行方式
- 室友、宠物、家具、洗烘、停车、楼层和无障碍等硬条件
- SSN/credit/income/guarantor 情况；不要索取号码或完整账单
- 是否愿意 sublease、合租、higher deposit 或合法范围内预付

城市/学校缺失且会改变库存或法律时最多问 3 个问题；如果只做 lease 条款审查，直接基于用户提供的文档开始。

## 硬筛选

1. 入住日和 lease term 可用。
2. `effective monthly all-in` 不超过预算。
3. 高峰通勤和夜间回程不超过上限。
4. 宠物、室友、停车、洗烘等不可妥协条件满足。
5. 申请材料路径覆盖 no-credit/international applicant 情况。
6. 发现要求 gift card、crypto、看房前异常 wire、拒绝书面 lease、身份不明收款方时淘汰。

## 搜索顺序

1. 物业官网或正式 leasing office：实时 inventory、fee sheet、qualification criteria、special 与 lease sample。
2. 学校 off-campus housing/transport/police 与市县官方 crime/tenant 页面。
3. 地图的高峰通勤、校车时刻与夜间步行路线。
4. Apartments/Zillow 等成熟平台用于补充库存与历史。
5. 最近 6–12 个月评论用于反复出现的虫害、隔音、维修、拖车和押金问题。

## 统一成本公式

`总租住成本 = base rent × 月数 + mandatory fees + utilities + internet + insurance + parking + commute + move-in/move-out costs - guaranteed concessions`

`effective monthly all-in = 总租住成本 ÷ 实际居住月数`

不把“最高可达”“满足特定 term 才享受”的 concession 当成保证。标明 refundable deposit 与真实费用的区别。

## No-credit 申请包

- 护照/签证/I-20 的必要页面；仅通过物业正式渠道提交
- admission/employment letter
- 可适当遮盖账号的资金证明
- guarantor 条件与第三方 guarantor 服务总费率
- higher deposit/prepay 仅在当地法律和退款条款允许时考虑

## 证据冲突

- Listing 与官网价格不同：官网书面 quote/fee sheet 优先，并标明报价有效期。
- Leasing agent 口头承诺与 lease 不同：以最终书面 lease/addendum 为准；要求补入文件。
- 官方 crime 数据与评论观感不同：分别呈现，避免把“安全”写成绝对承诺。

## Lease 核对清单

- concession clawback、late fee、early termination、sublet/relet、notice deadline
- utilities billing、pest、parking/towing、pet、guest、roommate replacement
- move-in inspection、维修责任、move-out cleaning、deposit return
- arbitration、attorney fees、joint and several liability、自动续租

## 输出结构

1. 核验日期、硬约束、默认假设。
2. 淘汰表与理由。
3. 3–5 个 shortlist：all-in、通勤、资格路径、证据状态、风险。
4. 最省钱 / 最均衡 / 最省心与明确首选。
5. Tour 路线、要问的话、索取文件清单。
6. Human gate：申请费、押金或签 lease 前停下核对收款方和最终文件。

## 失败回退

- 无匹配库存：扩大通勤圈、调整入住日/term、改合租或 sublease，明确每项代价。
- 无信用/担保：向物业索要书面 alternative documentation policy，不猜。
- 官网无 fee sheet：标为成本未验证，不进入首选。
- Lease 与营销承诺冲突：不签，要求 addendum 或放弃。
