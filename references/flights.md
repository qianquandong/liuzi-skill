# 回国机票与航班

## 最少输入

- 出发城市/可接受机场、国内目的地
- 日期窗口、停留时间、最多转机次数
- 行李、舱位、是否接受过夜/self-transfer
- 身份/签证对过境与再入境的限制

## 搜索流程

1. 跑日期网格，比较附近机场和中国境内可替代落地点。
2. 优先比较同一票号联程；self-transfer 单独标红风险。
3. 核验每段承运人、行李直挂、行李额度、座位和改退。
4. 查过境签证/入境要求，官方来源决定结论。
5. 算 all-in：票价 + 行李 + 选座 + 地面交通 + 酒店 + 国内段。
6. 给最省钱、最均衡、最省心；说明为什么推荐。

## 风险淘汰

- 转机时间不满足机场/航司实际要求
- separate tickets 且缓冲不足
- 行李不直挂但用户无法入境取行李
- OTA 售后差异未算入

价格、时刻、行李、改退和入境规则每次重查；需要监控时记录精确路线、日期、转机上限和通知阈值。
