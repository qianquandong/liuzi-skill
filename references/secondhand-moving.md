# 二手家具与搬家

## 买二手

1. 搜同款新价、近期成交/挂牌价和尺寸。
2. 向卖家要型号、年龄、瑕疵、宠物/烟、虫害、取货楼层。
3. 软体家具重点检查 bed bug、气味、污渍；风险不明直接放弃。
4. 电子/可调家具现场通电测试，拍 serial/model。
5. 公共场所或有人陪同取货；未验货不付不可追回款。
6. 把租车、人工、楼梯、工具和时间算入 all-in。

## 卖二手

- 标题写品牌 + 型号 + 尺寸 + 状态 + pickup 区域。
- 照片含全景、细节、瑕疵、功能证明。
- 定价参考本地同款，不把原价当成交价。
- 用“先到先得、现场验货、确认收款后搬走”。

## 搬家公司比价

统一提供地址区域、楼层/电梯、房型、重物、距离、日期、是否打包。要求书面列明小时价、最低时数、travel fee、楼梯/重物费、保险和取消条款。
