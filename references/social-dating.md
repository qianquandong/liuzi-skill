# 约会与找对象

## 先明确

- 城市、年龄范围、认真关系/轻松约会
- 语言文化偏好、宗教/生活方式硬条件
- 线上 app、线下活动或熟人介绍的接受度

## 执行

1. 按目标选择 1–2 个渠道，不同时经营很多平台。
2. Profile 用具体生活场景，照片清晰真实，不暴露住址/工牌/证件。
3. 聊天尽快验证基本信息和意图；持续回避视频/见面、索钱、投资拉群是红旗。
4. 第一次见面选公共场所，自行往返，共享位置，不透露精确住址。
5. 结束后按价值观、沟通一致性、边界感和行动匹配度评估，不只看“聊得热闹”。

## 输出

给渠道选择、profile 修改、开场白、first-date 方案和安全 checklist。不要代替用户发送或提交资料，除非明确授权且发送前确认。
