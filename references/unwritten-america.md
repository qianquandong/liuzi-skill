# 没人告诉你的美国常识

每个问题用四段：一句话结论 → 为什么 → 你怎么做 → 坑。

## 高频主题

- 浴室：很多住宅不是整间防水，水只留在 tub/shower 区域。
- 小费：先看账单是否已含 gratuity/service charge，再按场景决定。
- 医疗账单：provider、facility、lab、保险 EOB 可能分开且延后到达。
- 租房信用：房东用信用/收入评估付款风险；国际学生可走替代材料。
- 警察拦车：不要自行下车；安全靠边、双手可见、按指示行动。
- 押金：move-out 后可能因清洁、损坏、notice 或 concession 条款扣款。
- “We should hang out sometime”：通常只是友好表达；有具体日期才算计划。
- “How are you?”：多数是简短问候，不一定邀请长篇近况。
- 税和标价：零售标价常未含 sales tax；餐厅还可能有小费/服务费。
- 信用卡：按时全额还 statement balance，不需要付利息来建立信用。

地方差异、费用和法律权利必须再加载对应 playbook 并实时查。
