# F-1 / J-1 / CPT / OPT / STEM OPT

这是高风险路由。结论必须带核验日期和官方来源；不替代 DSO 或律师。

## 事实收集

- 当前 status、学校/项目、program end date
- I-20/DS-2019 当前授权类型与日期（不收完整 SEVIS ID）
- 行为是什么、是否有报酬、谁控制工作、发生地点和日期
- 是否涉及出境、失业天数、地址/雇主变化

## 回答流程

1. 把事实与用户猜测分开。
2. 查 USCIS、Study in the States/SEVP、ICE、CBP 与学校国际生办当前页面。
3. 写“官方明确事实 / 依赖学校或个案 / 风险未决”。
4. 对 CPT、OPT、STEM OPT 核验资格、时间、雇主要求、报告义务和文件。
5. 自媒体变现、1099、创业、unpaid internship、跨境远程工作不可只按付款来源判断。
6. 提供给 DSO/律师的事实清单和可复制问题。

## Human gate

提交 I-765、更新 SEVIS、接受工作、离职、出境或开始变现前，要求用户确认并在高风险时升级专业人士。
