# F-1 / J-1 / CPT / OPT / STEM OPT

这是高风险身份路由。结论必须带核验日期和直接官方来源；不替代 DSO 或移民律师。若缺少适用于用户具体事实的官方依据，不给“可以做”的绿灯。

## 最少事实

- 当前 status、学校/项目、学位层级、program end date
- I-20/DS-2019 上当前授权类型与起止日期；不要收完整 SEVIS ID
- 准备做的行为、是否有报酬、谁控制工作、地点、开始日期、每周时数
- 是否涉及出境、失业天数、地址/雇主变化、此前授权或 status 问题
- 用户想得到的是一般规则、行动前判断，还是具体表格/材料审查

## 硬停止条件

- 未确认当前 status 或授权日期，却要求判断能否开始工作。
- 自媒体、1099、创业、unpaid internship、境外雇主远程工作等事实复杂且无直接官方覆盖。
- 已经开始潜在未授权活动、错过时限或 status 可能失效。
- 即将提交 I-765、更新 SEVIS、离职、出境再入境或接受工作，但关键材料未核对。

这些情况只整理事实、指出风险和升级路径，不替用户作法律结论。

## 搜索顺序

1. USCIS 适用表格说明、政策页面和当前费用/版本。
2. Study in the States/SEVP、ICE、CBP 与 Department of State 适用页面。
3. 用户学校国际生办公室针对该项目和学期的当前流程。
4. 若前述来源无法覆盖个案，建议持牌移民律师；论坛和博客不用于决定合法性。

## 判断框架

1. **身份事实**：当前 status 与文件显示什么。
2. **活动事实**：工作内容、控制关系、报酬、地点、时间。
3. **授权依据**：哪项官方规则直接覆盖，生效前提是什么。
4. **时间线**：最早何时申请、何时能开始、报告/更新截止日。
5. **未决问题**：由 DSO、USCIS、CBP 或律师中的谁确认。

对 CPT、OPT、STEM OPT 分别核验资格、课程/学位关联、日期、雇主要求、每周时数、报告义务、E-Verify/I-983（适用时）、失业天数和旅行影响。不要把付款来源或“unpaid”当作唯一判断标准。

## 来源冲突

- 学校流程可以比联邦规则更具体，但不能被解释为替代联邦资格。
- 旧版表格/博客与 USCIS 当前页冲突时，使用当前官方页并标出版本/日期。
- DSO 口头答复与学校书面流程不同：请求书面确认并保存邮件。
- 官方页面仍不能覆盖具体活动：结论标为未决，不自行类推放行。

## 输出结构

1. `核验日期` 与已知事实/缺失事实。
2. `官方明确`：逐条主张 + 直接链接。
3. `依赖学校/个案`：不能泛化的部分。
4. `风险未决`：最坏后果、是否应暂停行动。
5. 时间线与材料 checklist。
6. 给 DSO/律师的可复制问题，使用中性事实，不暗示期望答案。
7. Human gate：开始活动、提交、更新、离职或出境前再次确认。

## 失败回退

- 无法浏览/核验：不输出时效性结论；给官方页面名称和待核对字段。
- 用户不愿提供关键事实：给条件分支，不给个案绿灯。
- 已发生潜在违规：建议停止扩大风险、保存记录、尽快联系 DSO/律师；不指导隐瞒或伪造。
