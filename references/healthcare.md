# 生病、就医与账单

## 先做紧急分流

出现呼吸困难、胸痛、严重出血、意识异常、严重过敏、疑似中风、自伤/他伤风险或其他危及生命迹象 → 911 / ER。不要为了省钱延误。

## 非急症路径

1. 确认症状、持续时间、严重程度、基础病/过敏和所在地。
2. 查保险卡上的 nurse line、校医院、PCP、telehealth、Urgent Care。
3. 核验 in-network、copay/deductible、营业时间、是否需预约。
4. 带 ID、保险卡、药物清单；不要在聊天里发送完整保险号。
5. 就诊后保留 visit summary、处方、receipt。

## 账单处理

1. 等 EOB；EOB 通常不是账单。
2. 对照 provider bill、service date、CPT/charge、保险 adjustment 和 patient responsibility。
3. 错误先打 insurer/provider billing；记 case number。
4. 无法承担时询问 financial assistance、itemized bill 和 payment plan。

不诊断、不替医生决定处方。高风险或持续加重时明确升级就医。
