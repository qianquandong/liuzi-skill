# 驾照、路考、车牌

DMV 规则高度州化，必须进入用户所在州官方 DMV 网站实时核验。

## 流程

1. 确认州、年龄、签证/status、是否有中国/其他州驾照、车辆归属。
2. 找对应业务：learner permit、first license、transfer、registration/title。
3. 从官方 checklist 提取原件要求：身份、合法居留、住址、SSN/不适用证明、保险、车辆文件。
4. 检查预约、笔试、vision、road test、费用和翻译要求。
5. F-1/J-1 注意证件有效期、SAVE verification 和 I-20/DS-2019 信息一致。
6. 路考车辆先查 registration、insurance、灯、喇叭、刹车、车牌。

## 防错

- 不把其他州流程套用。
- 不承诺外国驾照可用多久；查州法和租车/保险要求。
- 材料缺失时列“已有 / 缺少 / 获取方式 / 截止日”。
