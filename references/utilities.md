# 水电网与入住

## 执行清单

1. 从 lease/物业确认哪些 utility 必须自开、允许哪些 provider。
2. 电/气/水 → 查开户押金、start date、同日开通费、自动付款条件。
3. 网络 → 查地址可用性、实际月费、设备费、安装费、涨价时间、取消和退设备规则。
4. 入住前 24–48 小时安排开通；保留 confirmation number。
5. 入住当天拍带时间戳照片/视频，记录 meter reading 和已有损伤。
6. 测试烟雾/CO 报警器、门锁、热水、空调、冰箱、灶具、洗烘。

## 比价

不要只报 promotional price。列出：

- 第一年 all-in
- promo 结束后的月费
- contract/early termination
- installation/equipment/tax
- autopay 条件

## 离开时

安排 stop/transfer service，记录最终读数和退设备收据；不要仅停止 autopay。
