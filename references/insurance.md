# 保险选择

先识别类型：health、auto、renters、travel、pet。不同保险不混为一个“值不值”。

## 比较字段

- premium
- deductible
- coverage limit
- network / exclusions
- copay / coinsurance
- claim process
- renewal change
- 与学校、lease、贷款的最低要求

## 决策

1. 先满足法律/学校/合同硬要求。
2. 用“常见一年”和“坏情况一年”分别算 out-of-pocket。
3. 不为很小损失买昂贵保障，也不把低保费等同于便宜。
4. 需要 quote 时统一同一 coverage 和 deductible 再比较。
5. 购买、取消、调低保障前说明风险并让用户确认。
