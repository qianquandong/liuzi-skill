# 留学生申请 SSN 全流程（F-1 / J-1 / M-1）

SSN 跟着“工作授权”走，不跟着“学生身份”走。先判断能不能申请，再备材料，最后才约办公室。申请材料和时限必须在本次回答中打开 SSA 当前页面核验；本文件里的规则快照只用来定位要核对哪些字段。

## 最少事实

- 身份类型：F-1 / M-1 / J-1 / F-2 / J-2，以及 program 是否 active
- 入境日期、到校 check-in 日期（决定 SEVIS 是否已更新）
- 工作授权类型：校内工作 offer、CPT、OPT / STEM OPT（EAD 卡）、J-1 sponsor 授权，或“还没有工作”
- 工作开始日期（校内 / CPT 开始日离申请日超过 30 天会被退回）
- 申请 SSN 的真正目的：上班发工资、报税、开户、办卡、租房、手机分期

不要收集 SSN 全号、护照号、I-94 号、SEVIS ID、EAD 卡号或精确住址。

## 硬停止条件

- 没有任何工作授权，只是想用 SSN 开户、办信用卡、租房或“先办着”：SSA 不会仅为上学发号。直接转到替代路径，不帮用户“想办法办下来”。
- F-2 / 其他无工作授权的家属：同样没有工作授权，不能按学生流程申请。
- 用户想找人开“挂名 offer”、自拟雇主信或改日期凑 30 天窗口：拒绝，这是向联邦机构提交虚假材料。
- 已经在未授权的情况下开始工作：停止扩大风险，转 [immigration-school.md](immigration-school.md) 的升级路径。
- OPT 的 EAD 开始日期还没到：SSA 不受理，先等到 EAD 生效日。

## 规则快照（核验日期：2026-09-18，运行时必须重新核验）

来源：SSA Publication No. 05-10181《International Students and Social Security Numbers》（2024 年 1 月版）与 SSA “Request Social Security number for the first time” 页面。

1. 资格：一般只有获得 DHS 工作许可的非公民能申请；不会只为入学发号。
2. 等待：SSA 建议到学校报到后等 48 小时再申请，便于 SSA 与 DHS 核验身份。
3. 渠道：先在 SSA 网站在线开始申请，再在 45 个自然日内带原件去 Social Security office 或 Card Center 完成；部分人可在线自约时间。无法在线开始的，直接去办公室。
4. 费用：免费。任何收费“代办”都不需要。
5. 身份材料：未过期护照 + 入境章，I-94（如有）；F-1 / M-1 加 I-20；J-1 加 DS-2019。
6. 工作材料：
   - 校内工作（F-1）：DSO 信（写明学生身份、当前在读状态、雇主与工作类型）+ 雇主信或最近工资单。雇主信需主管签名和日期，写明职位、开始日期、工作时数、主管姓名与电话。
   - CPT（F-1）：DSO 签好 CPT 就业页的 I-20。
   - OPT / STEM OPT：EAD 卡（Form I-766）。
   - J-1：sponsor 抬头、原始签名的工作授权信。
7. 年龄证明：有外国出生证明或 10 个工作日内能拿到就要带；拿不到时 SSA 可考虑护照或 DHS 文件。
8. 原件：只收原件或签发机构认证的副本；复印件、公证件、申请回执都不收。
9. 退件情形：校内 / CPT 工作开始日距申请日超过 30 天；EAD 开始日期在未来。
10. 到卡时间：SSA 页面写“批准后 5–10 个工作日邮寄”，05-10181 写“多数在批准后 14 天到”。以当次页面为准，并告诉用户两者都存在。
11. 等卡期间：SSA 不要求有 SSN 才能开始工作；雇主可以用 SSA 的“已申请”证明信先入职发薪。
12. OPT 捷径：填 I-765 时勾选申请 SSN 卡，USCIS 会把资料传给 SSA，不需要再去办公室；卡会在收到 EAD 后约 14 天内单独寄到 I-765 上的地址。

## 搜索顺序

1. SSA：`ssa.gov/number-card/request-number-first-time`、05-10181（国际学生）、05-10096（非公民）。
2. USCIS：I-765 表格说明中关于 SSN 卡的部分（OPT 路径）。
3. 学校国际生办：校内工作 / CPT 的 DSO 信怎么开、多久出。
4. SSA office locator：离用户最近的 office / Card Center、是否可预约。
5. 社区经验（Reddit、学校群）只用于“哪个办公室排队短”“几点去人少”，不用于判断资格或材料。

## 全流程

1. **判断资格**：有无工作授权 → 属于校内 / CPT / OPT / J-1 哪一类 → 开始日期是否在 30 天内（校内 / CPT）或已生效（EAD）。
2. **选路径**：OPT 还没提交 I-765 → 直接在 I-765 里勾选申请 SSN；其他情况 → SSA 在线开始 + 办公室完成。
3. **等系统更新**：到校 check-in 至少 48 小时后再去；刚入境的先确认 I-94 信息正确（姓名、出生日期、身份类别），有误先找 CBP 修正。
4. **开信**：向 DSO 申请 SSN 用信（校内工作），向雇主要签名雇主信；CPT 确认 I-20 就业页已签。
5. **在线开始**：SSA 网站在线填写申请，记下确认信息；从这天起算 45 天内必须到办公室。
6. **约 / 去办公室**：能在线自约就约；不能约就早去，带齐原件。
7. **现场核对**：姓名拼写与护照、I-94 一致；邮寄地址能稳定收信（宿舍收发室、公寓 mailroom 要写对 unit）。
8. **拿回执**：要一份“已申请 SSN”的证明信给雇主入职用。
9. **等卡与跟进**：超过当次页面写的时间仍未收到，打 SSA 电话查询，不要重复申请。
10. **收卡以后**：原件锁起来，不随身带；把 SSN 更新到学校 payroll、银行和已有账户；以后换 OPT、H-1B 或绿卡都沿用同一个号，不重新申请。

## 没有工作授权时的替代路径

- 开户：多数银行学生账户可用护照 + I-20 开，按银行官方页面核验，转 [money-credit.md](money-credit.md)。
- 信用卡 / 信用记录：走无 SSN 的官方路径或 ITIN 路径，转 [money-credit.md](money-credit.md)。
- 报税：F-1 即使没收入也可能要交 8843；需要纳税识别号时看 ITIN（W-7），转 [taxes.md](taxes.md)。
- 租房：国际生 guarantor、预付或学校住房，转 [housing.md](housing.md)。
- 驾照：按州 DMV 的“SSN 不适用”流程，转 [dmv.md](dmv.md)。

## 常见坑

- 以为 SSN 是“留学生标配”，没工作也去排队，白跑一趟。
- 校内 offer 离入职还有一个多月就去申请，因超过 30 天被退。
- 刚入境第二天就去，DHS 记录未更新，被要求改天再来。
- 带护照复印件或公证件，被拒收。
- 在线申请后超过 45 天没去办公室，只能重新来。
- 卡上写着“VALID FOR WORK ONLY WITH DHS AUTHORIZATION”之类的限制说明，被误解成“办错了”。有这类说明是正常的，以卡面实际文字为准。
- 付费找中介“代办 SSN”：官方免费，且必须本人办理。
- 把 SSN 发到群里、发给“房东”或“HR”换取所谓审核：先转 [identity-security.md](identity-security.md) 排查诈骗。

## 输出结构

1. `核验日期`，以及已知事实 / 缺失事实。
2. **资格结论**：能申请 / 暂时不能（差什么）/ 不适用，附 SSA 直接链接和证据状态。
3. **路径**：I-765 勾选，或 SSA 在线开始 + 办公室。
4. **材料 checklist**：用 [checklist.md](../templates/checklist.md)，列“已有 / 缺少 / 找谁拿 / 截止日”。
5. **时间线**：最早可去日期（报到 + 48 小时、开始日前 30 天内）、45 天截止日、预计到卡时间。
6. **可复制话术**：向 DSO 要信、向雇主要信、SSA 电话查进度。
7. Human gate：去办公室前再核对一次材料原件；SSN 到手前不把号码或卡面照片发给任何人。

## 失败回退

- 无法联网核验：只给流程框架和要核对的字段，不写当前时限、到卡天数或材料清单为确定事实。
- 用户没说工作授权类型：先按“无授权 / 校内 / CPT / OPT”四个分支给条件结论。
- 用户所在办公室现场要求和 SSA 公开页面不一致：以书面规则为准，礼貌请对方说明依据；仍被拒就记下日期和办公室，联系 DSO 协助或换办公室再去。
- 卡超时未到或信息印错：联系 SSA 更正，不要自己重新提交一次新申请。
