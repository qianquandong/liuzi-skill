# 刚落地美国

## 先确认

- 机场、学校/城市、落地时间
- 今晚住址大致区域、是否有人接、行李件数
- 手机是否支持 eSIM、是否已有可用银行卡

## 执行顺序

1. 入境文件 → 护照、签证、I-20/DS-2019、学校联系方式放随身包。
2. 通信 → 优先开临时 eSIM/Wi-Fi；套餐价格与覆盖实时查，不硬编码。
3. 到住处 → 比较学校接机、正规 rideshare、机场 taxi 和公共交通；深夜不安排复杂换乘。
4. 现金与支付 → 先保证一张国际卡可用；不要携带大量现金四处走。
5. 72 小时内 → check-in、学校国际生要求、I-94 核对、银行、长期手机、交通卡。
6. 7 天内 → housing、utilities、基本采购、医疗入口和紧急联系人。

## 输出

按“今晚 / 72 小时 / 第一周”给 checklist；标出营业时间、预约要求和真实交通成本。

## 红线

- I-94 信息不一致 → 保存记录并按 CBP/学校流程处理。
- 陌生人要求代带行李、借卡、收验证码 → 拒绝。
- 精疲力尽或深夜落地 → 安全和少换乘优先于省十几美元。
