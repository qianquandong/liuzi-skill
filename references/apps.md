# 初到美国常用 App

按任务推荐，不给一屏“必装大全”。所有价格和可用性实时查。

| 任务 | 类别 | 核验点 |
|---|---|---|
| 地图/公交 | 地图与当地 transit | 离线地图、末班车、实时延误 |
| 打车 | 正规 rideshare | 机场 pickup 点、动态价、安全功能 |
| 付款 | 银行官方 App / P2P | 收款人身份、不可追回付款风险 |
| 外卖/杂货 | 配送平台 | menu markup、fee、tip、membership |
| 二手 | Marketplace/OfferUp/Buy Nothing | 验货、公共地点、诈骗 |
| 活动 | Meetup/Eventbrite/学校平台 | 活动是否真实、报名、recurring |
| 医疗 | 保险/医院 portal | network、账单、消息、隐私 |

只推荐解决当前问题所需的 3–6 个，并给设置顺序与隐私权限建议。
