# 身份盗用与账户安全

## 高风险信号

- 未申请的账户/硬查询、陌生账单、税表或政府通知
- 验证码请求、远程控制、gift card/crypto、异常 wire
- “立即逮捕/取消签证/断电”的高压威胁

## 处理顺序

1. 不点消息里的链接；从官方 App/官网独立进入。
2. 改受影响账户密码，撤销会话，开启 MFA。
3. 联系银行/发卡行 fraud 部门，锁卡并记录 case。
4. 从三家 credit bureau 查看报告；需要时 freeze，而不只是 fraud alert。
5. 通过 IdentityTheft.gov 等官方渠道建立恢复计划。
6. 保存时间线、截图、金额、号码；必要时报校警/当地警方。

不要在聊天里收集完整 SSN、卡号、验证码或账户密码。
