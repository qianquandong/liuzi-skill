# 降低生活费

## 审计顺序

1. 拉近 3–6 个月账单，按住房、交通、饮食、保险、订阅、购物、旅行分类。
2. 分开固定支出、可变支出、一次性支出；不要把退款重复算作收入。
3. 先砍低痛感高金额：闲置订阅、重复保险/服务、套餐溢价、late fee。
4. 再优化大项：房租 all-in、车、保险、外食、手机网络。
5. 学生优惠必须查当前资格、续费价和自动续订。
