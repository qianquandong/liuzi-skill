# 搬家后地址与邮件

## 地址类型

区分 residential、mailing、billing、legal/registered、vehicle/DMV、school/employer。不要用一次修改覆盖所有类型。

## 执行

1. 从邮件、账单和账户清单找出仍使用旧地址的机构。
2. 优先级：政府/移民、DMV、雇主/学校、银行/信用、保险、医疗、utilities、购物订阅。
3. USPS forwarding 只是兜底，不替代逐个更新。
4. 每项记录旧/新地址类型、提交日期、confirmation、验证方式。
5. 配偶和其他成年人账户需本人授权，不代为更改。
6. 30/60/90 天检查漏寄、退信和旧址通知。
