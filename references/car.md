# 第一辆车 / 租车

## 先算可承受成本

不要只用购车价。计算：

`OTD + 利息 + 保险 + 税/registration + 油费 + 维修保养 + 停车/toll - 预计残值`

先拿保险 quote，再决定车型；年轻驾驶人的保险可能改变整个选择。

## 买二手车流程

1. 确定 OTD 上限、用途、里程、保有年限和不可接受 title。
2. 建立可靠车型池，再搜本地 inventory。
3. 每辆先拿 VIN → title/history、事故、里程、recall、盗抢。
4. 预约独立 PPI；卖家拒绝检查通常直接淘汰。
5. 试驾检查冷启动、警示灯、刹车、轮胎、空调、异响和高速稳定。
6. 要 itemized written OTD，拆出 add-on、doc fee、税、registration。
7. financing 比较 APR、term、total interest、prepayment penalty；不只比较月供。
8. 付款和过户按州官方要求执行，不交 gift card/crypto/异常 wire。

## Dealer 谈价

先谈 OTD，不谈“每月想付多少”。任何 warranty、protection、etching、GPS、service plan 单列，可拒绝项明确删除后重新打印合同。

## 租车

核验 underage fee、保险覆盖、additional driver、toll、里程、跨州、还车油量和押金。
