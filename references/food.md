# 餐馆、奶茶与中国胃

## 最少输入

- 大致位置、可接受车程、预算、人数、时间
- 菜系/辣度/忌口、是否要停车/包间/夜宵

## 实时筛选

1. 查今天实际营业时间与 last order，不只看“通常营业”。
2. 看最近 3–6 个月评论；识别换老板、品质波动、排队和卫生重复问题。
3. 用具体菜品判断，不只看总星级。
4. 计算人均 + 税 + 小费 + 停车/通行。
5. 给 1 个明确首选、2–5 个备选；3 家以上附地图或距离排序。

## 输出字段

- 推荐点什么 / 不建议点什么
- 人均 all-in
- 开车/步行时间、停车、等位
- 适合场景：工作日晚饭、聚会、约会、夜宵

不要把社交媒体热度等同于味道，也不要引用几年前的营业信息。
