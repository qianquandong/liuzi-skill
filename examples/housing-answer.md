# 示例：在美国学校旁边租房最应该注意什么？

> 这是格式示例。真实公寓、价格、crime data、班次和评论必须按用户学校与日期实时搜索。

1. Step 1｜先把“学校旁边”改成通勤硬条件
   → 学校/校区、入住日期、lease 长度
   → 月租上限要写 all-in，不只写 base rent
   → 没车时设：步行到校车站 ≤ 10 分钟、高峰总通勤 ≤ 30 分钟

2. Step 2｜先查安全
   → 看城市/校园官方 crime map，不只看一个网站的安全分
   → 搜最近 6–12 个月住户评论
   → 重复出现的 break-in、towing、门禁、包裹失窃才算强信号
   → 晚上实地走一次车站到公寓路线

3. Step 3｜查真实通勤
   → 早上 8 点和晚上 6 点分别跑路线
   → 查校车工作日班次、末班车、周末是否运行
   → 准备下雨/晚归替代方案及每月 rideshare 预算

4. Step 4｜把广告价换成 all-in
   → base rent - 满足条件的 concession
   → mandatory amenity/trash/pest/package fee
   → electricity/water/internet
   → parking + renters insurance
   → 申请费、admin fee、deposit 分开列

5. Step 5｜没 SSN/credit 先问申请路径
   → I-20 / admission letter
   → bank statement / funding letter
   → guarantor 条件
   → higher deposit 或 prepay 的书面条款

6. Step 6｜Tour 必查
   → 手机信号、噪音、虫害痕迹、水压、空调、洗烘、门窗
   → 停车位和 towing 标志
   → 要一份完整 fee sheet 与 sample lease

7. Step 7｜最后只留三档
   → 最省钱：all-in 最低且安全/通勤过线
   → 最均衡：通勤、风险、价格综合最好
   → 最省心：校车近、管理稳定、unit 内洗烘

**我最推荐：** 默认选“最均衡”，但只有实时查完具体房源后才点名。

**最容易踩的坑：** 只看 base rent；special 绑定特定 lease；忽略校车末班；口头承诺不进 lease；没看 towing 和 pest 评论。

**你现在直接做：** 发学校/公司、大致预算、入住日和是否有车，Agent 随即拉实时 shortlist。
