# 示例：大学生第一年有什么信用卡可以办？

> 这是决策格式示例。具体卡名、welcome offer、年费和申请条件必须实时查银行官方页面；不能承诺获批。

1. Step 1｜先分清你是哪一类
   → 无 SSN、无美国信用记录
   → 有 SSN、但信用档案很薄
   → 已有 6–12 个月记录

2. Step 2｜先看你已有的银行关系
   → 发工资/奖学金/生活费进哪家银行
   → App 里是否有 pre-approved / pre-qualified offer
   → 先用不会影响信用的预审，少做盲目 hard pull

3. Step 3｜第一张卡按三档筛
   → 最省钱：无年费 student card
   → 最均衡：无年费、有基础返现、对薄信用友好
   → 最省心：secured card，押金清楚且有毕业/转卡路径

4. Step 4｜核对 6 个字段
   → 是否接受无 SSN/ITIN 的申请人
   → annual fee
   → foreign transaction fee
   → credit-building/reporting
   → deposit/refund（secured card）
   → welcome offer 的真实消费门槛

5. Step 5｜不要为了奖励乱花钱
   → 只用本来就会发生的学费、书本、生活采购
   → 不确定学校刷卡手续费时先算净收益
   → 无法全额还款就不追 welcome bonus

6. Step 6｜开卡后这样用
   → 设置 autopay `statement balance`
   → 到期日前保证账户有钱
   → 不需要留下利息来“养信用”
   → 定期核对三家 credit report

7. Step 7｜申请前最后检查
   → 近期 hard inquiries
   → 收入填写是否符合银行定义
   → 地址、姓名、SSN/ITIN 信息一致
   → 提交前由用户亲自确认

**我最推荐：** 第一张优先无年费、能稳定获批和长期保留的产品；奖励排在获批概率和正确用卡之后。

**最容易踩的坑：** 同一天申请很多张；把 minimum payment 当全额；为了信用故意付利息；用第三方过期 offer；虚报收入。

**你现在直接做：** 告诉 Agent 你有没有 SSN、在哪家银行、有无信用记录和月消费，Agent 再实时列具体卡。
