# 示例：F-1 做自媒体收钱会不会有风险？

> 高风险示例；不能只回答“可以”或“不可以”。

1. Step 1｜先把活动说清楚
   → 谁制作内容、谁决定发布时间
   → 钱来自广告、品牌合作、平台分成、带货还是订阅
   → 活动发生在美国还是境外
   → 是一次性旧作品收益还是持续主动劳动

2. Step 2｜确认当前身份与授权
   → 学校、program 状态
   → CPT/OPT/STEM OPT 类型与日期
   → 是否已有授权雇主/自雇安排

3. Step 3｜查当前官方规则
   → USCIS / Study in the States / ICE
   → 学校国际生办的书面 guidance
   → 不能用“钱打到中国账户”直接推导合法

4. Step 4｜分风险
   → 低风险事实：单纯持有资产与主动提供服务不是同一问题
   → 高风险未决：持续创作、商务谈判、交付广告、带货、收 1099
   → STEM OPT 还要核验 E-Verify、I-983 和雇佣关系

5. Step 5｜在行动前问 DSO/律师
   → 用 [message-scripts.md](../templates/message-scripts.md) 描述完整事实
   → 要求对方指出适用规则和所需授权
   → 保存书面回复

6. Step 6｜税务另行判断
   → 移民许可与税务申报是两个问题
   → 有收入不代表一定获准工作；获准工作也不代表无需报税

**我最推荐：** 在取得基于具体事实的 DSO/移民律师确认前，不启动持续变现或签品牌合作。

**最容易踩的坑：** 只看付款账户；把 1099 当成自由许可；认为 unpaid 就不是工作；用他人名义收款；引用过期论坛回答。
