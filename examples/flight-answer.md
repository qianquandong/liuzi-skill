# 示例：12 月回长沙，最多转一次，怎么最便宜？

1. Step 1｜锁定硬条件
   → 出发机场与可接受周边机场
   → 去/回日期窗口
   → 最多一次转机、托运行李件数
   → 是否接受在中国其他城市落地后高铁/国内段

2. Step 2｜跑日期网格
   → 比较窗口内前后 2–3 天
   → 同时查长沙与主要入境城市 + 国内衔接

3. Step 3｜先排除“看似一次，实际 self-transfer”
   → 是否同一票号
   → 行李是否直挂
   → 是否需要入境取行李再托运
   → 错过后续航班由谁负责

4. Step 4｜算真实总价
   → fare + baggage + seat
   → 去周边机场交通/停车
   → 过夜酒店
   → 国内机票/高铁

5. Step 5｜核验规则
   → 航司当前行李与改退
   → 过境国签证/入境
   → 回美所需身份文件

6. Step 6｜只给三档
   → 最省钱：允许合理地面衔接的最低 all-in
   → 最均衡：同票联程、转机时间舒服、总价合理
   → 最省心：单次转机、行李直挂、售后清楚

**我最推荐：** 默认同票联程的“最均衡”，除非 self-transfer 至少便宜到足以覆盖酒店、误机和重新购票风险。

**你现在直接做：** 给出出发城市、具体日期窗口、回程日和行李，Agent 应立即实时搜索，不能用示例价格回答。
