# 示例：预算 $10k，第一辆二手车怎么买才不被坑？

1. Step 1｜把 `$10k` 定义成 OTD 还是车价
   → 若是总预算，税、title、registration、PPI 和首轮维修都要留空间
   → 再设每月保险硬上限

2. Step 2｜先拿保险 quote
   → 同一驾驶人、地址、coverage 比 3–5 个候选车型
   → 保险太高的车型先淘汰

3. Step 3｜建立车型池
   → 按可靠性、维修成本、用途、里程和保有年限筛
   → 不因“一辆价格便宜”临时改变成高风险车型

4. Step 4｜每辆先查 VIN
   → title brand、事故、里程、recall、盗抢
   → salvage/rebuilt 若是硬性不要，直接淘汰

5. Step 5｜必须独立 PPI
   → 找与卖家无利益关系的 mechanic
   → 升车检查 leak、brake、suspension、tire、rust 和 scan codes
   → 卖家拒绝 PPI，通常直接走人

6. Step 6｜只谈 written OTD
   → vehicle price、doc fee、add-on、tax、title、registration 全拆开
   → 不先回答“你想月供多少”

7. Step 7｜决定
   → 最省钱：私人卖家 + 完整记录 + PPI 通过
   → 最均衡：可靠车型 + 清洁 title + 合理里程 + 可验证维护
   → 最省心：信誉较稳 dealer/CPO，但必须看 all-in

**我最推荐：** 把总预算的一部分留给税费、PPI 和第一年维修，并选择 PPI 结果最好而不是挂牌价最低的车。

**你现在直接做：** 发城市、OTD 上限、用途、预计年里程和 3 个 listing，Agent 可继续做 VIN/价格/保险核验。
